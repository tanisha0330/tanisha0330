### About

</div>

<p align="center">
I build crash-safe storage engines, agentic AI systems, and event-driven backends.<br/>
Most of my work sits at the intersection of <b>systems programming</b>, <b>distributed infrastructure</b>, and <b>intelligent agents</b> —<br/>
things that need to be fast, reliable, and smart enough to reason about their own state.
</p>

<div align="center">

### What I've Built

</div>

<table align="center">
<tr>
<td width="50%" valign="top">

**[Crash-Safe KV Store](https://github.com/tanisha0330/Crash_safe_kv)**<br/>
An LSM-tree key-value engine written from scratch in C++ — WAL with fsync, skiplist memtables, SSTable compaction, and bloom filters. Survived 100 kill/restart cycles with zero data loss. No third-party dependencies.

</td>
<td width="50%" valign="top">

**[Mnemos](https://github.com/tanisha0330/mnemos-conflict-resolution)**<br/>
Agentic memory system that treats observations as claims, not facts. Detects contradictions via vector similarity, resolves conflicts through deterministic rules + LLM arbitration on AWS Bedrock, and keeps full provenance history. Built on CockroachDB.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**[TicketFlow](https://github.com/tanisha0330/Microservices_Ticket_booking)**<br/>
13-service event-booking platform — FastAPI microservices, Redis seat-locking with TTL, Redpanda event streaming, AI agent layer for support/refunds, and full observability with Prometheus + Grafana + Jaeger. Ships with K8s manifests and chaos tests.

</td>
<td width="50%" valign="top">

**[DriftGuard](https://github.com/tanisha0330/Github-Dependency-Upgrade-Agent)**<br/>
Context-aware dependency upgrade agent. Parses AST call sites, retrieves changelogs and GitHub issues via hybrid RAG (Qdrant), and generates test-verified patches with cited evidence. Built with LangGraph. Human-in-the-loop before any merge.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**[Scam Shield AI](https://github.com/tanisha0330/scam_bust_ktj_challenge)**<br/>
Mobile app protecting senior citizens from financial scams — screens SMS/WhatsApp for phishing, monitors live calls for coercion patterns, and alerts trusted contacts. Local-first ML with cloud LLM fallback. Flutter + Django + PyTorch, supports English and Hindi.

</td>
<td width="50%" valign="top">

**[Lexicognition VivaBot](https://github.com/tanisha0330/lexicognition_viva_voce)**<br/>
AI research paper examiner — ingests any PDF, generates adaptive questions, grades answers against retrieved evidence, detects contradictions, and returns a skill radar. RAG pipeline with ChromaDB, voice I/O via Whisper, powered by LLaMA 3.3 70B on Groq.

</td>
</tr>
</table>
